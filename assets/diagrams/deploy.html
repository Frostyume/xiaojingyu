DEPLOY · 3 PHASES · 6 STEPS

从零到她在群里说话

准备三样东西 → 把一句话交给 agent → 亲手扫码并验收。

XIAOJINGYU · 1.0.0
01

准备

先有三样东西

01

装好 DSH

你

小鲸鱼的大脑。从官方渠道安装并启动，浏览器能打开就算成功。

http://127.0.0.1:3080
02

打开一个 agent

你

Codex、Claude Code、Qoder 或 DSH，任选一个能执行命令、读写文件的。

能执行命令 + 读写文件
02

交给 agent

一句话，四个回答

03

原样发一句话

你

把 README 里的部署提示词整段复制，发给它。

帮我部署 github.com/Frostyume/xiaojingyu…
04

回答后全自动

AGENT

告诉它 QQ 号、白名单、SnowLuma 端口、模型名；克隆、依赖、配置、preset、重启 DSH、doctor 都由它做。

clone → npm install → config → install-dsh → doctor
03

扫码上线

只有扫码必须你亲手

05

SnowLuma 扫码

亲手

官方下载 → launcher.bat → 扫码登录 QQ → 开启 WebSocket 与 HTTP API。

ws://127.0.0.1:3001 · http://127.0.0.1:3000
06

验收上线

亲手

doctor 全绿 → 白名单私聊发一句「在吗」→ 打开控制台。

npm run doctor → 私聊「在吗」→ 127.0.0.1:3100
完成的标准是：doctor 没有 FAIL、白名单私聊收到回复、控制台能打开——而不是「命令跑完」。
