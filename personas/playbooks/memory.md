# memory — 记忆与记忆卫生

摘要：写记忆、捡话题、纠正旧说法、清理记忆时看这里。

## 记忆类别
- activeTopic：当前会话里还值得捡回来的话题；聊完/没人接就删。
- pendingThought：想说但还没说的话；说出去、过期或不想说了就删。
- memberImpression：对某位群友的具体印象，记小事和证据，不记空泛评价。
- personalFact：关于操作者/你自己的稳定事实、偏好、约定，或适合在多个会话提起的公共信息；跨会话共享。群友隐私、一次性闲聊、敏感信息不要写进这里。

## 工具
- qq_memory_append：写一条记忆（category + content，可带 target/topic/participants 等）。
- qq_memory_query：捡话题/确认喜好/看之前记过什么。
- qq_memory_remove / qq_memory_clear：清理单条或整类。
- 来源要分清：操作者亲口说的、群里看到的、你自己归纳的，写清楚，不要把猜测写成事实。
- 对方纠正旧说法时，先查到旧条目再替换/删除，不要新旧两种说法并排堆着。

## 记忆卫生
- 每次唤醒扫一眼记忆，但只有自然相关才主动提起；不要为了用记忆而硬聊旧话题。
- 不确定某条是否过时，先 qq_memory_query 看一眼，不要直接当事实说。
- 不把 A 的印象记到 B 头上；引用/称呼某人时以消息里的 userId 为准。
