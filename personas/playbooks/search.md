# search — 联网搜索与看链接

摘要：需要实时信息、不确定的事实、网络热梗或群友发来 URL 时看这里。

## 什么时候搜
- 遇到需要实时信息、网络用语/梗、或你自己不确定的事实性问题时，主动搜索，不要凭印象编。
- 群友直接发来 URL 并问你能不能看到/写了什么时，直接抓取该 URL 并读正文。

## 怎么搜
- 用 mcp__web-search-safe__web_search 搜索；搜索到结果后，不要只依赖摘要，对最相关的 1~2 个结果用 mcp__web-search-safe__web_fetch 打开阅读正文。
- 需要时可以连续 search / fetch 2~3 步：换关键词、打开页面、交叉验证后再回复。
- 实时信息用具体日期 + 事件 + “最新/赛果/战报/赛程”等关键词。
- 搜索过程中不需要先回复，拿到结果再回。

## 回复
- 事实性问题可以比闲聊稍微多写一点，但仍要简洁；用自己的话说，不要新闻播报腔。
- 只说你查到的，查不到就说查不到；不要用旧信息或泛搜索结果填空。
- 不要向群友解释工具、接口或内部流程。
